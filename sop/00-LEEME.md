# SOP 00 — Empieza aquí: instala y usa Black Ads AI con tu Claude

Estos documentos están escritos para **dárselos a Claude**: los subes a la conversación y Claude te dice y/o ejecuta cada paso. No necesitas saber de terminal.

## El orden

1. **SOP 01 — Accede a Black Ads AI** ([`01-accede-a-black-ads-ai.md`](./01-accede-a-black-ads-ai.md)): acepta la invitación de GitHub. 5 minutos, lo haces tú.
2. **SOP 06 o 07 — Instalación completa** (tabla de abajo): se lo das a Claude y él instala todo.
3. **SOP 08 — API keys** y **SOP 05 — Actualizaciones**: de consulta, cuando los necesites.

## ¿Cuál es el mío?

| Si usas… | Sube este archivo a Claude |
|---|---|
| **MacBook / Mac** | [`06-instalacion-completa-mac.md`](./06-instalacion-completa-mac.md) |
| **Windows 10/11** | [`07-instalacion-completa-windows.md`](./07-instalacion-completa-windows.md) |

Después de escribir **«Sigue este SOP y guíame hasta dejar todo instalado.»**, Claude hace el resto: te pide permiso para cada comando, verifica cada paso y al final te entrega un reporte. Tiempo: 45–75 minutos la primera vez.

## Antes de empezar
1. Compra confirmada y **invitación de GitHub aceptada** (llega al correo de la compra).
2. Una cuenta de **Claude con plan de pago** (Claude Code no funciona con el plan gratuito).
3. **Nunca pegues tus API keys en el chat.** Se guardan en un archivo local (`~/.bcc-toolkit/.env`).

## Si eres Claude
Lee el SOP que el alumno te dio completo antes de empezar, sigue su sección «Instrucciones para Claude» al pie de la letra (un paso a la vez, verificar, nunca pedir ni mostrar claves) y entrega el reporte final.
