# SOP 01 — Accede a Black Ads AI

**Para quién:** compradores de Black Ads AI que todavía no han entrado al repositorio privado.
**Resultado:** tu cuenta de GitHub queda dentro de la organización privada `Black-Copy-Club` y ya puedes ver los archivos del toolkit.
**Tiempo:** 5 minutos.
**Versión de este SOP:** toolkit 1.2.3 · revisado el 2026-10-11.

---

## Lo que tienes que saber antes

- **Black Ads AI no se descarga de un link público.** Vive en un repositorio **privado** de GitHub, dentro de la organización `Black-Copy-Club`. Solo entran las cuentas invitadas.
- **Tu invitación ya salió.** Cuando pagaste, un sistema automático le envió una invitación de GitHub **al mismo correo con el que compraste**. Esa invitación es tu llave: sin aceptarla, ningún paso de instalación funciona.
- **GitHub y Claude son dos cosas distintas.** GitHub es donde viven los agentes (las skills). Claude es donde los usas. Necesitas cuenta en los dos.

## Paso 1 — Ten una cuenta de GitHub con tu correo de compra

Si ya tienes cuenta de GitHub con ese correo, salta al Paso 2.

Si no: entra a https://github.com/signup y créala **con el mismo correo con el que compraste** Black Ads AI. Es gratis. Confirma el correo con el código que te llega.

> ¿Tu cuenta de GitHub usa otro correo? Agrega el correo de compra en https://github.com/settings/emails y confírmalo. La invitación aparecerá en esa cuenta.

## Paso 2 — Acepta la invitación

1. Busca en tu correo el mensaje de GitHub con el asunto **«…invited you to join the Black-Copy-Club organization»**. Revisa también spam y promociones.
2. Toca **View invitation** y después **Join Black-Copy-Club**.

¿No encuentras el correo? Inicia sesión en GitHub y abre https://github.com/orgs/Black-Copy-Club/invitation: si la invitación existe, aparece ahí.

## Paso 3 — Comprueba que tienes acceso

Abre https://github.com/Black-Copy-Club/ads-video-workshop

- **Ves una lista de archivos** (carpetas `plugins` y `sop`, archivo `README.md`): ya tienes acceso. Sigue con el SOP de instalación de tu computador.
- **Ves un error 404 («Page not found»):** la invitación no está aceptada, o iniciaste sesión con otra cuenta de GitHub. Repite el Paso 2 con la cuenta correcta.

## Problemas frecuentes

| Qué pasa | Qué hacer |
|---|---|
| No me llegó ninguna invitación | Revisa spam y promociones del correo de compra. Si no está, escribe a soporte@blackcopyclub.com con el correo de compra y tu usuario de GitHub. |
| La invitación expiró (duran 7 días) | Escribe a soporte@blackcopyclub.com y la reenviamos. |
| Compré con un correo y GitHub lo tengo con otro | Agrega el correo de compra a tu cuenta de GitHub (Paso 1) o pide a soporte que invite a tu usuario. |
| Veo el 404 aunque acepté | Cierra sesión en GitHub y vuelve a entrar con la cuenta que aceptó la invitación. |
